# Paczki aktualizacyjne

Tutaj publikujemy archiwa ZIP wydań Informatyk-24.

## Wymagania
- Nazwa pliku: `Informatyk-24-X.Y.Z.Z-strona5.zip` (wersja zgodna z manifestem).
- W archiwum: `release.json` oraz katalog `files/`.
- Manifest paczki: format `i24-update-v1`, środowisko `strona5`, lista plików z SHA-256.
- Suma całego archiwum ZIP jest zapisywana w głównym `manifest.json`.
- Nie publikować danych klientów, konfiguracji, haseł ani tokenów.

Nie umieszczać tutaj paczki, dopóki jej zawartość i sumy kontrolne nie zostaną sprawdzone.
